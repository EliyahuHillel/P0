# nodebb-plugin-emergency-rebuild

כפתור חירום נסתר: כתובת סודית שמריצה `./nodebb build` + `./nodebb restart`
ישירות בשרת, **בלי** לעבור דרך מנגנון ציור העמודים (views) של NodeBB - ולכן
ממשיכה לעבוד גם כשהאתר כולו (כולל ה-ACP) מציג שגיאת 500 מהסוג
"Failed to lookup view! Did you run `./nodebb build`?".

## מגבלה חשובה - קראו לפני שמסתמכים על זה

זה עוזר **רק** כשתהליך NodeBB עצמו חי ורץ, ופשוט נכשל בציור עמודים (בדיוק
המקרה שכבר קרה לכם). אם התהליך של NodeBB עצמו קורס/נהרג לגמרי (לא רק
שגיאת עמוד, אלא שהשרת "מת" ולא עונה בכלל) - שום פלאגין לא יכול לעזור,
כי קוד של פלאגין רץ *בתוך* אותו תהליך בדיוק. למקרה כזה צריך מנגנון "שומר"
נפרד ברמת מערכת ההפעלה של השרת (pm2/systemd) - וזה דורש גישה אמיתית לשרת
(SSH) להגדיר, לא ניתן לבנות את זה כפלאגין.

## התקנה (ACP → הרחבות → תוספים → מציאת תוספים)

חפשו `emergency-rebuild`, התקינו, הפעילו, ואז "בניה מחדש והפעלה מחדש" כרגיל
דרך ה-ACP (בפעם הזו, כשהכל עדיין תקין).

**שימו לב**: הפלאגין הזה **לא** דורש הדבקת שום קוד ב-Custom JS - הוא פועל
כולו בצד השרת. אין לו שום ממשק גלוי - זו הכוונה.

## הגדרה חד-פעמית (כשהאתר בריא ותקין)

1. מתחברים לפורום כמנהל.
2. פותחים קונסולת מפתחים בדפדפן (F12 -> Console) בכל עמוד בפורום.
3. מדביקים ומריצים:
   ```js
   socket.emit('plugins.emergencyRebuild.getMyKey', {}, console.log)
   ```
4. מודפסת תשובה עם מפתח סודי אקראי, לדוגמה:
   ```json
   { "key": "a1b2c3d4...", "url": "/emergency-rebuild" }
   ```
   שומרים את זה במקום בטוח ונגיש (הערה בטלפון, מייל לעצמכם) - **לא**
   משתפים עם אף אחד אחר.
5. הכתובת המלאה לשעת חירום היא:
   ```
   https://הדומיין-שלכם/emergency-rebuild?key=המפתח-שקיבלתם
   ```
   שומרים אותה (Bookmark) בטלפון, כדי שתהיה נגישה גם אם האתר קורס.

## שימוש בשעת חירום

נכנסים לכתובת השמורה מכל דפדפן/מכשיר - **גם בלי להיות מחוברים לפורום
בכלל** (זה בכוונה, כדי שזה יעבוד גם אם משהו בהתחברות עצמה שבור). מחכים
כדקה-שתיים לתשובה בעמוד (בנייה מלאה לוקחת זמן), ואז מרעננים את האתר הרגיל.

תשובה לדוגמה בהצלחה:
```
הבנייה הסתיימה בהצלחה!
השרת מופעל מחדש עכשיו - חכו כ-15-30 שניות ואז רעננו את האתר הרגיל.
```

אם רואים שגיאה במקום זה - זו שגיאת ה-build האמיתית, מודפסת ישירות בעמוד -
אפשר להעתיק ולשלוח כדי לאבחן מה בדיוק נכשל.

## אם חוששים שהמפתח דלף

מריצים מהקונסולה (כשהאתר בריא):
```js
socket.emit('plugins.emergencyRebuild.regenerateKey', {}, console.log)
```
המפתח הישן מפסיק לעבוד באופן מיידי, ומתקבל מפתח חדש - צריך לעדכן את
ה-Bookmark השמור.
